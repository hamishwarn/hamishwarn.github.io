Conway's Game of Life

Welcome! This is a browser port of a Conway's Game of Life simulator that I originally wrote in MATLAB, complete with a heatmap or image display mode, several classic starting patterns, a live population chart, and a custom mode where you can draw your own starting grid by hand.

Open Github

Background & the four rules

Conway's Game of Life is a cellular automaton devised by the British mathematician John Conway in 1970. It is a game with no players - its evolution is determined entirely by its initial state.

The game consists of a large grid of cells which can be either live or dead. In this simulation, live cells are shown as white pixels, while dead cells are shown as black. Each cell interacts with its eight neighbours, being the cells adjacent to it horizontally, vertically, or diagonally.

The four rules:

  1. Any live cell with fewer than two live neighbours dies (underpopulation).
  2. Any live cell with two or three live neighbours lives on to the next generation.
  3. Any live cell with more than three live neighbours dies (overpopulation).
  4. Any dead cell with exactly three live neighbours becomes a live cell (reproduction).

The game proceeds in discrete steps, with the above rules applied to every cell in the grid, over and over, generation after generation.

Image is a plain pixel grid; Heatmap draws cell gridlines when zoomed in.
Larger grids show patterns like the Ark or Glider Gun more fully, but run a little slower. 100+ is recommended for those two.

Choose a starting position

Custom mode is only available with the Image display style. Choosing it while Heatmap is selected will offer to switch you over.

1. Custom

Draw your own pattern by hand (Image mode only).

2. Random

Each cell is live or dead with 50/50 chance.

3. All live

Every cell starts alive.

4. R-Pentomino

A tiny, famously chaotic long-lived pattern.

5. Single Line

A long horizontal line of live cells.

6. Acorn

A small seed that grows for a very long time.

7. Glider Gun

A gun that fires a steady stream of gliders.

8. Ark

A pattern that regenerates activity for a long time.

Custom mode needs Image display

Custom mode isn't supported in Heatmap format. Would you like to switch over to Image format and continue into custom mode, or return to the choice menu?
